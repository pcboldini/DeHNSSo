# DeHNSSo-v1 test cases

Three of the cases published with DeHNSSo-v1 (Westerbeek et al., CPC 302 (2024) 109250),
each in its own folder with a caller and the reference data it is compared against.
The fourth v1 case, crossflow instability over a step, is not included here; its v2
counterpart is `callers/benchmark/cfi_step.m`.

| folder | v1 case | status |
|---|---|---|
| `TS_Blasius/` | TS waves in a Blasius boundary layer | runs |
| `CFI_SweptWing/` | crossflow instability in a swept-wing boundary layer | runs |
| `CFI_SweptWing_hump/` | crossflow instability over a hump | runs |

## Running one

Each caller needs its stability grid built first:

```matlab
run TS_Blasius/gridgen_ts_blasius.m            % then TS_Blasius/caller_ts_blasius.m
run CFI_SweptWing/gridgen_cfi_flat_plate.m     % then CFI_SweptWing/caller_cfi_flat_plate.m
run CFI_SweptWing_hump/gridgen_cfi_hump.m      % then CFI_SweptWing_hump/caller_cfi_hump.m
```

The two swept-wing cases read their base flows from `baseflow/output/`, generated by the
callers in `baseflow/caller/`. The Blasius case reads the base flow of DeHNSSo-v1,
`Data Files/BF_Blasius.mat`, which is not shipped with DeHNSSo-v2. Clone DeHNSSo-v1 next to
this repository with `git clone https://github.com/SvenWesterbeek/DeHNSSo DeHNSSo-v1`, or set
`v1dir` in `gridgen_ts_blasius.m`. The grid it produces is shipped as `sample/input/DeHNSSo_input_sample.mat`.

Each caller runs its case on DeHNSSo-v1's own grid and settings and overlays the v1
reference data. They are not the same calculations as `callers/benchmark/`: those are
the paper's cases on DeHNSSo-v2's benchmark grids, whereas these reproduce the v1
setups (the hump, for instance, on v1's 1000 x 50 Chebyshev grid rather than the
benchmark's 1200 x 80 FD grid) so that v2 can be checked against v1 like for like.

## Reference data

| file | source |
|---|---|
| `StabRes_Blasius_NPSE.mat`, `StabRes_Blasius_LPSE.mat` | nonlinear and linear PSE |
| `StabRes_SweptWing_flat_NPSE.mat`, `_LPSE.mat`, `_DNS.mat` | nonlinear PSE, linear PSE, DNS |
| `StabRes_SweptWing_Hump_AHLNS.mat` | AHLNS |

All are the files shipped with v1 in `Data_Files/`.
